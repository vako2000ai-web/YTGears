# YTGears / Gear & Porcelain

Независимое ядро интерактивного механизма для будущей реалистичной YouTube-сцены: шестерни взводят молоточек, после полного оборота последней ступени происходит удар по фарфоровой вазе.

**Сейчас реализованы расчёты, жизненный цикл раунда, имитация входных событий и проверки. Реалистичной 3D-сцены, звука и подключения к YouTube/платежам пока нет.**

## Быстрый запуск

Нужен .NET SDK 10.0 (ядро собирается для .NET Standard 2.1). Из корня репозитория:

```powershell
dotnet build YTGears.sln -c Release --disable-build-servers -m:1
dotnet run --project tests/YTGears.Checks -c Release --no-build
dotnet run --project src/YTGears.Simulator -c Release --no-build -- examples/baseline.json
dotnet run --project src/YTGears.Simulator -c Release --no-build -- examples/interactive.json
```

Симуляция работает быстрее реального времени: базовый раунд 1800 секунд не требует ожидания 30 минут. Для машинного отчёта добавьте `--json` после имени сценария.

Проверки запускаются командой `dotnet run`, а не `dotnet test`: это исполняемый набор доменных и интеграционных проверок без сторонних пакетов. Ошибка проверки даёт код выхода 1; ошибка сценария — 2.

## Статус правил

Первая ступень: 12 секунд на оборот; исходные N=8, T=1800 секунд. N и T меняются в JSON перед созданием раунда. Все углы вычисляются от одного времени τ.

Формула зрительского ускорения, сглаживание, срок действия донатов, их накопление и предел скорости **предварительные**. В демонстрации по умолчанию используется один ненакопительный эффект ×2 при активной сумме от 1 USD, до конца раунда. Вариант `2^floor(S)` доступен только через явный выбор `WholeDollarsDoubling`.

Число уникальных зрителей и уникальных ускоривших выводится как недоступное. Отдельно сохраняется наблюдаемый пик одновременного онлайна; он не подменяет уникальных людей.
