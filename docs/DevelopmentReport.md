# Отчёт: перенос на Python и 3D-сцена

18 октября 2026. По прямому поручению пользователя C# заменён на Python и создана 3D-сцена. Исходные требования v1.2 сохранены. Предыдущая C#-версия остаётся в истории Git.

## Работает

- `start.bat` готовит окружение и запускает обычное 3D-окно; `run.py` по умолчанию открывает сцену.
- Python-ядро сохраняет N/T, первый период 12 с, единое время, непрерывные углы, скорость, один контакт и замороженные итоги.
- Для 3D подбираются целые зубья с точным произведением отношений; неподдерживаемые N/T отклоняются. При N=8/T=1800 — 8 валов, 14 колёс, периоды 12/24/48/96/192/384/768/1800.
- Металлические колёса с эвольвентными боковыми гранями, спицами и отверстиями, оси/основание/опоры; фарфоровая ваза с орнаментом и внутренней поверхностью; взвод молоточка.
- Один удар скрывает целую вазу и запускает 160 объёмных осколков с Bullet, гравитацией, трением, полом/подиумом и CCD. Через 6 секунд появляется экран итогов.
- Есть оригинальные синтезированные звук механизма, удар/черепки и музыка; приглушение при ударе, отключение M.
- Локальные кнопки зрителей/донатов, настройки, пауза, быстрый демораунд, камера, полный экран, скрытие UI и снимки.
- JSON-сценарии прежнего формата сохранены; денежный вывод теперь строковый Decimal, ключи отчёта snake_case.

## Фактически выполненная проверка разработки

Python 3.14.0, Panda3D 1.10.16, simplepbr 0.13.1, Windows. Зависимости установлены в `.venv`. Выполнены рендеры обычной сцены и фазы разрушения на OpenGL, изображения визуально просмотрены; исправлены пути шрифта, вызов DirectEntry и ориентация граней. Сценарий interactive на Python даёт 859.5 с, один удар, два доната и 1.5 USD, с отклонением повторного/конфликтующего/pending/позднего события. Базовый и экспериментальный сценарии также доступны автономно.

Дополнительно выполнены установленная версия трёх JSON-сценариев (1800 / 859.5 / 109 с), ускорение USD до 900 с и повторный вызов после финала. Через API реальной 3D-сцены проверены кнопки доната/зрителей/паузы, сохранение раунда при несовместимой геометрии, создание 160 физических тел и финальный экран. После 6.5 с физики центры фрагментов в этом прогоне не опускались ниже −0.15. Это ограниченная проверка текущего набора фрагментов, а не гарантия для любых настроек. Создан и просмотрен кадр итогов. Обычное окно YTGears запущено, процесс отвечает. Изображение текущей сцены сохранено в `docs/preview.png`.

## Ограничения и незавершённое

Это работающий **3D-прототип**, не финальная реалистичная сцена. Материалы и формы процедурные, разрушение регулярное/runtime, а не запечённое в Blender. Точное физическое касание молоточка и полная механика защёлки не подтверждены. Фоновая музыка — простой синтезированный слой для дальнейшего саунд-дизайна.

YouTube и реальные платежи не подключены; интерфейс подписывает события как имитацию. Уникальные зрители/ускорившие недоступны. Политики скорости предварительные. Не все N/T физически поддерживаются; N в сцене означает валы, количество колёс показано отдельно. Защита платежей в памяти, восстановления и автоматических раундов нет. Производительность для конкретного ПК/FPS и работа OBS должны проходить отдельную приёмку.
